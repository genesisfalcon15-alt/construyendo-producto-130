# Vitta

Es una plataforma web orientada al fitness, bienestar y alimentación inteligente, diseñada para ayudar a las personas a construir hábitos saludables de forma práctica, visual y personalizada.

## Problema

El agotamiento mental hace que a muchas personas les cueste mantener una vida equilibrada. Cuando la mente está saturada, el autocuidado, la gestión emocional y la nutrición sana suelen pasar a un segundo plano.

## Solución

Vitta permite a los usuarios:

- Realizar un check-in diario.
- Recibir análisis asistido por IA.
- Obtener recomendaciones y prioridades diarias.
- Guarda todos los datos que aportan una mejora global a la salud. En función del estado de ánimo del usuario registrado, le guía para que pueda cumplir sus objetivos diarios.

## MVP Features.

- Registro e inicio de sesión.
- Check-in emocional diario.
- Análisis emocional con IA.
- Generación de prioridades.
- Historial de entrada.
