## Tech Stack - Vitta

### Frontend

- Nex.js

Framework basado en React para construir la interfaz de usuario.
Permite crear páginas rápidas, escalables y estructuradas.

- TailwindCSS  

Framework de estilos basado en clases utilitarias.
Permite diseñar interfaces de forma rápida y consistente.

## Backend

- Supabase 
- Autenticación de usuarios.
- Base de Datos PostgreSQL.
- Apis automáticas.


## Inteligencia Artificial

- Groq API 
- API utilizada para integrar modelos de lenguaje.
Permite analizar los check-ins del usuario y generar:
- Analisis emocional.
- Recomendaciones.
- Prioridades Díarias. 

## Arquitectura General

- Frontend (Next.js)  

- Supabase (datos + usuarios)

- Groq API (análisis IA)
