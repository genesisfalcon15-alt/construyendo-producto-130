# User Stories - Vitta

## Autenticación

Como usuario,
quiero registrarme en la aplicación,
para poder guardar mi información de forma personal.

Como usuario,
quiero iniciar sesión,
para acceder a mis datos y mi historial.


## Check-in diario

Como usuario,
quiero escribir cómo me siento cada día,
para poder expresar mi estado emocional.

Como usuario,
quiero guardar mi check-in diario,
para mantener un registro de mi evolución.

## Analisis con IA

Como usuario,
quiero recibir un análisis automático de mi estado,
para entender mejor cómo me encuentro.

Como usuario,
quiero obtener recomendaciones personalizadas,
para saber qué puedo hacer ese día

## Prioridades diarias

Como usuario,
quiero recibir 3 prioridades diarias,
para saber en qué debo enfocarme

## Historial 

Como usuario,
quiero ver mis entradas anteriores,
para revisar mi evolución con el tiempo.

Como usuario,
quiero ver recomendaciones pasadas,
para entender cómo ha cambiado mi situación.
