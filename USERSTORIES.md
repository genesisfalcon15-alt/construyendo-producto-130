# User Stories - Vitta

## Autenticación

Como usuario,
quiero registrarme en la aplicación,
para poder guardar mi información de forma personal.

Como usuario,
quiero iniciar sesión,
para acceder a mis datos y mi historial.

Como usuario, 
quiero poder cerrar mi sesión y que se guarden los datos.


## Check-in diario

Como usuario,
quiero tener una experiencia personalizada desde el inicio.

Como usuario, 
quiero tener un acceso directo a las funcionalidades. 

## Analisis con IA

Como usuario,
quiero recibir un análisis automático de mi estado global,
para entender mejor cómo me encuentro.

Como usuario,
quiero obtener recomendaciones personalizadas,
para saber qué puedo hacer hoy.

## Prioridades diarias

Como usuario,
quiero recibir recomendaciones diarias,
para saber en qué debo enfocarme

## Historial 
Como usuario,
quiero guardar mi check-in diario,
para mantener un registro de mi evolución.

Como usuario,
quiero ver recomendaciones pasadas,
para entender cómo ha cambiado mi situación.
